# Мастерская — H-01

Проект гуманоидного робота H-01. Текущая геометрическая редакция: [v0.3](robot/H-01/v0.3/README.md). Предыдущая редакция и исходные задания сохранены в `robot/H-01`.

Для переноса на другой компьютер клонируйте репозиторий и откройте `robot/H-01/v0.3/README.md`. Документы — Markdown, таблицы — CSV UTF-8, модель дерева — URDF.

Генератор `robot/H-01/v0.3/build_geometry.py` использует стандартную библиотеку Python 3. При запуске перезаписывает производные таблицы, URDF и отчёт проверки. Перед запуском прочитайте ограничения в README v0.3.

Нативные файлы Inventor пока отсутствуют. Геометрия идеализирована, компоновка и расчёты ещё не завершены.

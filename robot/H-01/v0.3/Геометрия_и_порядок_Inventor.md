# Пространственная постановка H-01 v0.3

## База и ноль

Правые системы: X вперёд, Y влево, Z вверх. `base_link` в точке P0: пересечение средней сагиттальной плоскости и поперечной конструктивной базовой оси таза. До создания реального таза это начало скелетной геометрии, которое нужно материализовать базовыми плоскостями/посадочными поверхностями. Центр масс не определяет P0.

В нуле base расположен в ground в (0,0,875) мм с одинаковой ориентацией. Ground — внешняя система, не фиксированное звено динамического робота. Корпус вертикален, руки вниз, ноги прямые, стопы параллельны +X. Все управляемые q=0; нулевой захват — условное положение открытого эквивалентного механизма. Энкодерный ноль и его калибровочные смещения неизвестны.

Все локальные системы при q=0 сонаправлены base: `origin_rpy=0`. Поэтому ненулевая ориентация оси задаётся `axis_xyz`, а не функциональным словом roll/pitch. При движении система дочернего звена поворачивается относительно родительской. Начало дочернего звена находится на входящем суставе, а не автоматически в центре детали или её массы.

## Главные точки при нулевых смещениях

Все значения ниже в мм относительно base; y>0 слева, y<0 справа.

|---|---:|---:|---:|---:|
| Тазобедренные ступени | 0 | ±90 | 0 | 875 |
| Колени | 0 | ±90 | −400 | 475 |
| Голеностопные ступени | 0 | ±90 | −790 | 85 |
| Системы подошв | 0 | ±90 | −875 | 0 |
| Талия | 0 | 0 | 100 | 975 |
| Шея | 0 | 0 | 525 | 1400 |
| Плечевые ступени | 0 | ±225 | 415 | 1290 |
| Локти | 0 | ±225 | 135 | 1010 |
| Предплечье roll / запястье | 0 | ±225 | −115 | 760 |

Высота плеча 1290, полуширина плеч 225, высота шеи 1400 и длина до TCP 160 — дополнительные допущения редакции, не значения, утверждённые пользователем. Высота оболочки головы не задана: H=1600 остаётся требованием к будущей оболочке, а не измеренным габаритом текущего дерева.

## Направления и знаки

Положительное движение определяется правилом правой руки вокруг фактического вектора `axis_xyz`.

| Сустав | Ось при q=0 | Предложенные пределы, градусы |
|---|---|---|
| hip yaw | +Z | −45…45 |
| hip roll | +X | −35…35 |
| hip pitch | −Y | −40…90 |
| knee pitch | +Y | 0…130 |
| ankle pitch | −Y | −30…45 |
| ankle roll | +X | −25…25 |
| waist yaw / pitch | +Z / +Y | −45…45 / −25…35 |
| neck yaw / pitch | +Z / +Y | −70…70 / −40…45 |
| shoulder yaw / roll / pitch | +Z / +X / −Y | ±90 / ±90 / −90…135 |
| elbow pitch | −Y | 0…135 |
| forearm roll | −Z | ±90 |
| wrist pitch | −Y | ±60 |

Положительные hip pitch и elbow pitch уводят нижележащее вертикальное звено вперёд. У колена положительное сгибание направляет голень назад относительно бедра. Название forearm roll означает вращение вокруг продольной оси предплечья: в выбранном нуле это −Z, а не глобальная X. Это уточняет обобщённую запись v0.2.

С одинаковой +X для roll обеих сторон положительные углы дают одинаковое глобальное направление вращения, а не одинаковое анатомическое отведение. Для симметричного отведения нужны противоположные знаки. Диапазоны пока заимствованы как ориентиры, а не проверены упорами, кабелями и столкновениями. Разделить в дальнейшем механический ход, программный предел и рабочий запас.

## Стопы и TCP

Подошва каждой стопы: прямоугольник X∈[−85,+165], Y∈[−55,+55] мм относительно её системы. Длина 250, ширина 110; ось голеностопа в (0,0,85). Расстояние до пятки 85 — новое компоновочное допущение. Контур фактической резиновой подошвы и распределение контактов не проверены.

TCP закреплён относительно gripper_body в (0,0,−160) мм. Его система пока сонаправлена gripper_body, условный вектор подхода — −Z_TCP, направление закрытия пальцев — Y_TCP. Имеется лишь эквивалентный ползун для одной координаты захвата, а не модель двух пальцев и их связи. `gripper_stroke=40 мм` — допущение; его нельзя считать фактической апертурой без механизма.

## Смещения и приводы

Порядок ступеней: таз yaw→roll→pitch; плечо yaw→roll→pitch; голеностоп pitch→roll; талия и шея yaw→pitch. Межосевые смещения записаны отдельными параметрами `*_stage2_d*`, `*_stage3_d*`. Сейчас все они равны нулю только для аналитического шаблона. Поэтому дерево в нуле может иметь совпадающие оси, а геометрия корпуса приводов ещё отсутствует.

Для тазовых, коленных и голеностопных приводов зарезервировать зоны вокруг соответствующих осей, для плеча/локтя/запястья — зоны в проксимальных участках модулей; точную сторону установки ещё выбрать. Для каждой зоны определить отдельно корпус, выходную опору, разъём, изгиб кабеля и подход инструмента. Таблица envelopes содержит ссылки на суставы, но размеры оставлены пустыми: выдуманные габариты не подтверждают размещение.

## Построение в Inventor

1. Создать скелетную деталь `H01_MasterSkeleton.ipt` с P0 и базовыми XY/XZ/YZ. Это предлагаемое имя; файл пока отсутствует.
2. Ввести пользовательские параметры и сохранить различие заданных пользователем размеров и новых допущений редакции.
3. Создать точки и рабочие оси из `joint_coordinates.csv`; для каждой ступени сохранить отдельное имя даже при совпадении координат шаблона.
4. Создать локальные системы и соединения по `joints.csv`; связывать параметры со скелетом, а не вручную дублировать координаты в деталях.
5. Добавить габариты стоп, системы TCP и изменяемые блоки приводов. Компоновкой заменить нулевые межосевые смещения.
6. Собрать кинематические звенья в `.iam`, проверить направления +q малыми поворотами каждого шарнира и согласовать зеркальность.
7. Проверить цепи и пересчитать высоту/расстояние стоп после ввода смещений. Затем выполнить T01–T08 с коллизиями, положением/ориентацией TCP и путём.

Для сопоставления CAD и URDF использовать одну нулевую позу и фиксировать ревизию. Здесь таблица координат — производная для нуля, а таблица суставов — локальная постановка для всех конфигураций. Для преобразований URDF принята стандартная семантика родитель→сустав и axis в системе сустава; [материалы ROSCon](https://roscon.ros.org/2019/talks/roscon2019_poseframespecificationforsdformat1_7.pdf).

# H-01.КС.01 — Габаритно-кинематическая записка

v0.2, 10.10.2026. Табличная постановка для CAD; чертёж и пространственные трансформации ещё не разработаны.

## Конфигурации

| Вариант | Голова | Талия | Руки | Ноги | Тело | Захваты | Всего управляемых осей |
|---|---:|---:|---:|---:|---:|---:|---:|
| Прототип B | 2 | 2 | 5×2 | 6×2 | 26 | 1×2 | 28 |
| Промежуточный | 2 | 2 | 6×2 | 6×2 | 28 | 1×2 | 30 |
| Расширенный A | 2 | 2 | 6×2 | 7×2 | 30 | 1×2 | 32 |

Для B рука: плечо yaw/roll/pitch, локоть pitch, предплечье roll; запястье фиксированное. Для A добавляется запястье pitch и одна независимая ось каждой стопы. Считать «внутренний балансир» эквивалентом шарнира носка нельзя: это разные механизмы. Оси дополнительных стоп должны быть определены до выпуска A.

Под DOF здесь понимаются независимые внутренние координаты механизмов; управление закрытием простого захвата — отдельная координата. Число двигателей не всегда равно DOF. Шесть координат свободного основания в динамической модели не включены в количество приводов. Контактные ограничения опоры также не изменяют каталог приводных осей.

## Координаты

Неподвижная система W: Z вверх, X вперёд, Y влево; правая тройка. В нулевой стойке система P в центре таза сонаправлена W. Yaw вокруг локальной Z, pitch вокруг локальной Y, roll вокруг локальной X. Положительный угол — по правилу правой руки.

Для цепей нужны локальные системы после каждого шарнира, порядок осей и постоянные трансформации между осями. CSV содержит функциональные названия и предложенный порядок, но не полный набор CAD/URDF-трансформаций. Пределы из исходника — анатомические ориентиры: знаки сгибания и зеркальность сторон нужно сопоставить с локальными осями. Их нельзя прямо импортировать как окончательные пределы URDF.

## Согласованный пример вертикальной компоновки

| Параметр | Предлагаемое значение |
|---|---:|
| Высота оси голеностопа от пола | 80 мм |
| Голень, между центрами колена и голеностопа | 400 мм |
| Бедро, между центрами таза и колена | 410 мм |
| Высота колена в выпрямленной стойке | 480 мм |
| Высота оси тазобедренного сустава | 890 мм |
| Высота плечевой оси | 1290 мм |
| Низ габаритной оболочки головы | 1360 мм |
| Высота оболочки головы | 240 мм |
| Верх головы | 1600 мм |

Величины 80+400+410=890 и 1360+240=1600 согласованы арифметически. Низ оболочки головы не обязан совпадать с осью шеи. Положение шеи, смещения тазовых осей и плеч уточняются CAD. В согнутой стойке рост уменьшится.

Остальные ориентиры исходника: плечи 420–480 мм, таз 300–360 мм, глубина торса 180–260 мм, плечо 260–300 мм, предплечье 240–280 мм, кисть 140–190 мм; стопа 220–280×90–130 мм. Предложение для скелета: плечо 280, предплечье 260, захват 160, стопа 260×120 мм. Уточнить, означают ли ширины габарит или расстояния между осями.

## Диапазоны исходника, градусы

| Узел | Ось | Ориентир |
|---|---|---|
| Голова | yaw / pitch | ±70 / −40…45 |
| Талия | yaw / pitch | ±45 / −25…35 |
| Плечо | yaw / roll / pitch | ±90 / ±90 / −90…135 |
| Локоть | pitch | 0…135 |
| Предплечье | roll | ±90 |
| Запястье A | pitch | ±60 |
| Таз | yaw / roll / pitch | ±45 / ±35 / −40…90 |
| Колено | pitch | 0…130 |
| Голеностоп | pitch / roll | −30…45 / ±25 |

Талия roll ±20° и запястье yaw ±45° оставлены за пределами этих конфигураций. Для захвата ход задаётся геометрией; исходник его не содержит. Для дополнительной стопы диапазон не задан.

## Дерево

```text
Таз
├── талия yaw → pitch → торс
│   ├── шея yaw → pitch → голова
│   ├── левое плечо yaw → roll → pitch → локоть pitch → предплечье roll → захват
│   └── правое плечо yaw → roll → pitch → локоть pitch → предплечье roll → захват
├── левый таз yaw → roll → pitch → колено pitch → голеностоп pitch → roll → стопа
└── правый таз yaw → roll → pitch → колено pitch → голеностоп pitch → roll → стопа
```

Проверить достижимость, сингулярности плеча, пересечения конечностей/панелей, кабельные петли, рабочую зону и пределы упоров. Нулевая поза и полные трансформации остаются открытыми задачами.

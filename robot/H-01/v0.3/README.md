## Категории данных

`working_architecture` — рабочий выбор для этой редакции, не окончательное утверждение.

`numerical_assumption` — стартовые численные значения пользователя, ещё не проверенные проектом.

`layout_to_verify` — размеры, смещения и положения, требующие компоновочной проверки. В частности, нулевые смещения многоосевых блоков не являются решением о совпадении реальных осей.

Все строки имеют `proposed`; значения `verified` и `approved` пока не присваиваются. Проверка суммы и структуры не превращает проектное допущение в утверждённый размер.

## Источник данных и обновление

Сейчас первичная численная запись находится в `build_geometry.py`; четыре CSV — согласованный снимок её результата. Генератор перезаписывает CSV, URDF и отчёт. Не редактировать их вручную с последующим запуском генератора: изменения потеряются. Для следующей редакции сначала перенести параметры и выражения в читаемый генератором внешний источник, затем подключать автоматическое построение Inventor. Текущий скрипт не является импортёром CSV в Inventor.

Смещения отражены в таблице параметров и ссылках `offset_prefix`. Для правой/левой сторон пока применён один общий набор смещений в сонаправленных локальных системах. После проектирования реальных зеркальных узлов нужны отдельные трансформации сторон. Изменение смещений потребует пересчёта положения стоп и нулевой стойки; текущая высота 875 мм справедлива только для нулевых смещений.

URDF содержит условные `effort=1` и `velocity=0.1` в единицах соответствующих суставов лишь для обязательных полей формата. Они **не являются характеристиками приводов или допустимыми пределами управления**. Использовать файл только как геометрическое дерево. Без масс, столкновений и приводных характеристик он не предназначен для физической симуляции.

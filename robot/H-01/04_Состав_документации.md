# Реестр документации H-01

v0.2, 10.10.2026. Обозначения внутренние; правила применяемых стандартов и оформления необходимо определить отдельно. ПТ/ЭП/ТП здесь — комплекты стадий, а не автоматически один документ. Записка КС не заменяет кинематическую схему установленного формата.

| Комплект | Состав | Текущее состояние |
|---|---|---|
| Техническое задание | Назначение, параметры, требования, приёмка | Рабочая редакция 01 |
| Техническое предложение | Варианты и обоснование архитектуры | Частично: 02, 03 |
| Эскизный проект | Компоновка, виды, кинематика, 3D | Записка 02; CAD и чертежей нет |
| Технический проект | Расчёты, узлы, интерфейсы, спецификации | Не разработан |
| Общие КД | Сборочный, габаритный, общего вида, кинематическая схема; спецификация, ведомости покупных изделий и спецификаций | Реестр, без чертежей |
| Механика по узлам | Сборка, детали, спецификация, 3D, материалы, допуски/посадки, крепёж и затяжка, сборочные требования | Не разработана |
| Электрика | Структурная, функциональная, принципиальная, соединений и подключений; питание, размещение, кабельный журнал, сигналы, перечень компонентов | Архитектура 03; схем нет |
| ПО | Модули, интерфейсы, состояния, движение, аварии, протоколы, телеметрия, симуляция, версии | Архитектура 03; реализация отсутствует |
| Расчёты | Масса/ЦМ, суставные моменты, мощность, редукторы, валы, оси, кронштейны, подшипники, жёсткость, энергия, тепло, баланс, автономность | Постановки 05, 06 |
| Эксплуатация | Эксплуатация, сборка, обслуживание, калибровка, паспорт, безопасность, ЗИП, ведомость эксплуатационных документов | Не разработана |
| Испытания | Программа, методики, протоколы и критерии | Предварительный план 08 |

Программу испытаний вести отдельно; её классификацию в комплекте согласовать с принятыми правилами. На каждый документ назначить обозначение, ревизию, автора, проверяющего и статус. Рабочие и выпущенные ревизии разделять. BOM верхнего уровня пока не является закупочной спецификацией.
